# 公益小助手

Android 上的多站点管理工具。把中转站账号、签到、余额、模型、令牌、聊天、本地网关、SSH、LINUX.DO 和短剧放进一个 APP 里。

最新版 **0.32.166**（2026-10-22），Android 8.0 及以上，只支持 ARM64，安装包约 96 MiB。

## 能做什么

- **站点**：支持 NEWAPI、One API、SUB2API、AIHubMix 和兼容站点；管账号、Cookie、余额、令牌、标签，能批量同步，也能给单个站点配代理。
- **签到**：自动、手动、站外签到，逐站看结果；登录失效可以在 APP 里重新验证后继续。
- **模型**：多站点多 Key 拉模型，测 OpenAI、Responses、Claude 三种协议，支持筛选、排序、别名和分组。
- **聊天**：流式回复、历史会话、语音输入和朗读；模型满载时可以排队候场。
- **本地网关**：手机开一个 OpenAI 兼容接口给电脑用，支持三种协议、SSE、模型路由和用量账本。
- **SSH**：终端、多会话、传文件、看服务器状态、管容器、端口转发，也能让 AI 帮忙排查。
- **LINUX.DO**：首页、帖子、回复、通知、关爱佬友，支持连续朗读和 BOOST 引用回复。
- **短剧**：多源搜索、分类、追剧、下载、投屏，源配置从后台同步。
- **其它**：资源浏览、听书、投屏、公益榜、公告、WebDAV 备份、主题和图标。

详细功能看 [功能地图](docs/FEATURES.md)，操作步骤看 [使用说明](docs/USER_GUIDE.md)。

## 上手

1. 装好 APK，按提示完成激活。
2. 在「站点」里添加网址、登录，然后点「同步数据」。
3. 填好站点的 API 地址和 Key，拉模型、测一下，再进聊天。
4. 要在电脑上调用，就打开本地网关，把地址、Key 和模型 ID 填到电脑客户端。
5. 短剧在「全部资源」里，先同步源配置；遇到验证提示在 APP 内完成。

## 几点说明

- 网关提供 `/v1/models`、`/v1/chat/completions`、`/v1/responses`、`/v1/messages`，但不等于所有供应商的扩展都支持，以实际测试为准。
- 短剧固定直连，不走 APP 代理和系统代理；系统 VPN、广告过滤仍可能影响连接。
- DoH 只是换一条加密 DNS/连接路线，不能保证永远免 Cloudflare 验证。
- 源的数量、名称和可用性由后台配置决定，以 APP 同步后的列表为准。
- 激活、续费、模型和第三方内容依赖各自服务，价格以 APP 当时显示为准。
