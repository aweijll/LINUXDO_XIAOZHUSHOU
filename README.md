# 公益小助手

面向 Android 的公益 API 站点聚合管理工具，用一个 APP 集中处理站点登录、签到、数据同步、API Key、本地路由网关、模型测试、模型聊天、LINUX.DO 浏览与网页朗读。

> 本仓库只提供官方 APK、使用文档和版本记录，不包含源代码。公开仓库不代表开源，未授予反编译、二次分发或修改应用的许可。

公益小助手不是 LINUX.DO 官方客户端，也不提供 API 中转服务、模型额度、站点账号或注册码。使用者需要自行拥有合法账号和凭据。

## 主要功能

- **多站点管理与自动自愈**：支持 NEWAPI、One API、SUB2API 和自定义站点，集中查看登录、余额、用量、公告、令牌与模型状态；集成后台静默登录自愈，CK 失效自动无感知修复更新。
- **自动签到（焚绝-极限白嫖 / 手动自动化）**：
  - **未登录站点正循环**：网页渲染后自动点击「使用 LinuxDO 继续」-> 自动点击授权「允许」-> 自动跳转至 `/profile` -> 连续多轮深度查找签到按钮自动点击 -> 确认签到成功后自动保存 CK 并无缝流转至下一站。
  - **已登录站点正循环**：自动检测登录态特征直接跳转 `/profile` 执行多轮签到查找与自动点击并保存。
  - **异常自愈**：打不开的站点自动刷新 1 次，仍打不开自动跳过；遇到 Cloudflare 等人机验证框等待手动打勾，打勾完成后自动恢复后续流程。
- **随身 API 本地路由网关控制台**：
  - 首页紧凑单行开关，点入独立全屏控制台（概览 / 路由 / 价格分析 / 日志 / 设置）。
  - NewAPI 级超全仪表盘：近 24 小时消耗、总消耗、今日/总请求数、Token 吞吐、总额度与剩余额度动态统计。
  - 智能路由与选站策略：模型站点卡片金色高亮实时余额，支持模型按需折叠与拖拽排序；可折算单次预计费用智能优选剩余调用次数最多的高性价比站点。
  - 路由日志全面重构：清晰分行排版呈现上游站点名称、模型协议、消耗金额、耗时与来源 IP。
- **令牌与模型全站拉取**：本地加密保存多个 API Key，支持遍历站点下所有有效 KEY 聚合拉取全量模型；支持 OpenAI、Codex、Claude 三种协议自动轮换测试和不可用模型清理。
- **模型聊天与候场保活**：流式回复、历史会话管理、语音输入、回复朗读；内置“模型候场助手”，满载模型自动有界探测，成功后振动提醒并多级延长保活。
- **LINUX.DO 浏览与朗读插件**：
  - 授权登录彻底放行跳转并支持“在外部系统浏览器中打开授权”。
  - 论坛朗读持续检测：向下滚动刷帖时持续增量追加新回复朗读，已读不重复，并彻底过滤“保存到本地”、“保存为图片”等非正文操作文字。
- **数据工具与备份**：二维码添加、数据导入导出、WebDAV 端到端 AES-256-GCM 加密备份与一键恢复。
- **个性化**：深浅主题、完整悠哉字体、桌面图标切换、代理和批量并发设置。

## 快速开始

1. 从 [Releases](https://github.com/aweijll/LINUXDO_XIAOZHUSHOU/releases/latest) 下载 APK。
2. 在系统设置中允许当前浏览器或文件管理器“安装未知应用”，完成安装。
3. 首次启动保持联网，按 APP 提示完成身份确认（支持内置授权或外部浏览器授权）和注册码激活。
4. 进入“站点”添加站点网址，在内置浏览器完成登录并保存。
5. 执行“同步数据”或开启自动签到，享受全自动数据拉取与签到自愈。
6. 进入站点详情的令牌管理配置 API 地址和 API Key，拉取模型后即可开启本地路由网关或聊天。

完整步骤见 [使用说明](docs/USER_GUIDE.md)。

## 权限与隐私

- 相机只用于用户主动扫码；麦克风只用于模型聊天的按住说话。
- 通知、前台服务、唤醒锁和电池优化豁免用于用户主动开启的候场、朗读及后台任务。
- 安装权限只用于下载更新后调起 Android 系统安装确认，不会静默安装。
- 站点 Cookie、API Key、激活令牌和 WebDAV 配置使用 Android Keystore 加密保存在本机。
- WebDAV 数据包在上传前使用独立密码加密；普通站点导出不包含 Cookie、令牌或 API Key。
- AI 报告会把脱敏后的任务内容发送到用户选择的模型线路，请自行评估第三方模型服务的隐私政策。

详细说明见 [隐私、安全与权限](docs/PRIVACY_AND_PERMISSIONS.md)。

## 重要限制

- APP 不会绕过验证码、Cloudflare、Turnstile 或站点安全规则，遇到验证时需手动在页面勾选。
- 第三方站点的接口、限流和维护状态可能变化，无法保证永久兼容。
- 后台运行受不同手机厂商省电策略影响，建议将电池优化设置为“不限制”。
- 自定义 HTTP 站点存在明文传输风险，涉及 Cookie 或 API Key 时应优先使用 HTTPS。
- 使用者应只管理自己有权访问的账户，并遵守 LINUX.DO、站点服务条款及当地法律法规。
