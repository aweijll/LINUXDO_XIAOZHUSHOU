## 这到底是个什么 APP？

它不是只能看余额的“小工具”，也不是只能聊天的“套壳页面”。它更像是你的 **AI 站点管家 + 模型工作台 + 手机服务器控制台**：

- 站点多、账号多、模型多？统一收进来。
- 每天签到麻烦？交给自动任务，遇到验证时再叫你处理。
- API Key 散落在各个站点？集中保存、批量拉取、统一测试。
- 想把手机变成自己的 OpenAI 兼容接口？打开本地网关即可。
- 想在手机上管服务器？直接进入 SSH-AI，一句话让 AI 帮你排查、执行和解释。
- 想看 LINUX.DO、听帖子、看资源、做投屏？不用再来回切应用。

## 最值得用的功能

### 1. 多站点管理：一眼看清所有站点

支持 NEWAPI、One API、SUB2API、AIHubMix 及其他兼容站点，也支持自定义站点。每个站点可以单独保存：

- 站点名称、网址、备注、标签和启停状态；
- 网页登录 Cookie 与管理会话；
- API 地址、分组和多个 API Key；
- 账户、余额、额度、用量、公告、签到和登录状态；
- 站点代理、任务模式、优先级和模型设置。

站点列表支持搜索、筛选、收藏、隐藏、状态排序、重复站点识别和批量操作。站点多了也不用靠记忆找，搜索一下就能直达。

### 2. 自动签到：能自动就自动，需要你时再提醒你

支持全自动签到、手动签到、站外签到、仅同步数据和不参与任务等模式。

自动签到会根据站点实际状态处理：

- 未登录：引导 Linux.do 授权，完成后进入个人中心签到；
- 已登录：直接寻找个人中心和签到入口；
- 找不到页面：自动刷新重试一次，仍失败就跳过，不把整个任务卡死；
- 遇到 Cloudflare、Turnstile 等人机验证：停下来等你手动勾选，完成后继续；
- 登录状态异常：优先尝试后台静默修复 Cookie，再重新检查；
- 每个站点都会留下结果，成功、跳过、待登录、待验证和失败一目了然。

你不用每天打开十几个站点重复点按钮，APP 会把重复劳动尽量做掉。

### 3. 模型中心：拉取、测试、筛选、清理，一站搞定

模型中心可以遍历多个站点和多个有效 API Key，统一拉取真实模型目录，不靠手工猜模型名。

支持：

- OpenAI Chat Completions；
- Codex Responses；
- Claude Messages；
- 自动识别常见 `/v1` 地址和协议；
- 单模型测试、批量测试、全站拉取并测试；
- 可用、不可用、未测试和暂时失败筛选；
- 模型名称、供应商、站点、协议和可用性筛选排序；
- 模型别名、启停、分组、批量删除和不可用模型清理；
- Cloudflare 或人工验证后的模型目录继续读取；
- 测试报告显示命中的站点、协议和失败原因。

模型测试会发出真实请求，可能消耗少量额度。超时不一定等于 Key 失效，也可能是站点拥堵、模型满载、DNS、TLS 或线路问题。

### 4. 模型聊天：流式回复、历史会话、语音输入和朗读

模型配置好以后可以直接聊天：

- 流式输出，边生成边看；
- 保存、继续和删除历史会话；
- 按住说话，松开发送，滑动取消；
- AI 回复语音朗读；
- 支持多协议模型；
- 支持服务器上下文，让 AI 根据服务器信息辅助排查；
- 会话中保留工具调用过程和结果。

### 5. 模型候场助手：满载模型也能等

遇到模型繁忙、排队或限流时，可以开启候场助手：

- 自定义探测间隔和并发数量；
- 支持 Codex Responses、Claude Messages 等协议；
- 成功后声音、通知和振动提醒；
- 按成功情况逐步延长间隔，避免无脑高频请求；
- 均衡模式和息屏高可靠模式可选；
- 受 Android 厂商后台策略影响，不能承诺系统永不清理进程。

### 6. 本地 API 网关：手机就是你的 OpenAI 兼容中转入口

打开 APP 首页的本地网关，手机就能提供 OpenAI 兼容接口，给电脑、平板或其他客户端使用。

网关包括：

- `/v1/models` 模型目录；
- `/v1/chat/completions` 聊天请求；
- 非流式和 SSE 流式返回；
- Bearer Key 鉴权；
- 仅本机回环或同一 Wi-Fi 局域网监听；
- 多站点、多模型、多协议统一路由；
- 余额、价格、成功率、请求数和 Token 统计；
- 路由策略、模型站点优先级和拖拽排序；
- 智能选择更适合当前请求的站点；
- 持久化日志和用量账本；
- 近 24 小时、今日和累计统计；
- 可选的防暴力破解保护和数据保留周期。

你可以把它接入 NewAPI、CC Switch、Chatbox 或其他 OpenAI 兼容客户端。网关默认需要用户主动开启，并且每次请求都需要本地 Bearer Key。

### 7. SSH-AI 智能助手：一句话解决你所有服务器的烦恼

`0.32.122` 已把 SSH-AI 直接融合到 APP 首页本地网关下方。它不是另一个孤立 APK，而是 APP 内的一整套服务器工作台。

支持：

- SSH 服务器连接和多会话管理；
- 终端实时输出、ANSI 颜色和滚动；
- 快捷键栏、命令面板、关键字高亮和终端搜索；
- AI 对话、历史会话和服务器上下文；
- 让 AI 帮你解释日志、排查故障、生成命令和分析配置；
- 文件浏览、上传、下载、重命名、删除和冲突处理；
- 远程目录选择和本地文件选择；
- sudo 提权提示和命令执行确认；
- 端口转发、SOCKS5 代理和代理跳转；
- systemd 服务管理、crontab、包管理和防火墙操作；
- Docker、Web Server、Caddy、Nginx 等服务器工作流；
- CPU、内存、磁盘、进程和运行状态查看；
- 本地机器、串口设备和远程服务器管理；
- 服务器连接导入、导出、凭据管理和加密保险箱；
- 内置 MCP、技能和可复用命令片段。

SSH-AI 会自动使用 APP 当前正在运行的本地网关：地址、Key 和模型目录实时同步，Key 不会写入 SSH 自己的数据库，也不会因为网关端口或 Key 变化而失效。

### 8. LINUX.DO 浏览、朗读和实用插件

内置 LINUX.DO 浏览器支持：

- Linux.do Connect 授权；
- 内置授权或外部 Chrome / Edge 授权；
- 普通网页浏览和安全跳转；
- 帖子、回复和排行榜浏览；
- 论坛长帖下拉后增量追加朗读；
- 已读内容不重复朗读；
- 自动过滤“保存到本地”“保存为图片”等干扰文字；
- 标题、正文、回复和用户名播报；
- Android TTS 或 Edge 在线语音；
- 播放、暂停、继续、停止和悬浮控制；
- 通知分类、未读角标和快捷入口；
- 抢注助手、公益站识别和主帖跳转。

### 9. 资源、视频、直播、听书和投屏

## 三分钟上手

1. 从 [Releases](https://github.com/aweijll/LINUXDO_XIAOZHUSHOU/releases/latest) 下载 APK。
2. 覆盖安装，不要先卸载旧版本。
3. 首次打开后完成 Linux.do 身份确认和注册码激活。
4. 进入“站点”，添加站点并完成网页登录。
5. 点击“同步数据”，确认余额、签到和登录状态。
6. 在站点详情配置 API 地址和 Key，点击“拉取模型”。
7. 测试模型后，可以直接聊天，也可以打开本地网关。
8. 想管服务器，首页点击 **SSH-AI智能助手**。
9. 想续费，在设置或到期页面直接进入续费。

## 重要说明

- 公益小助手不是 LINUX.DO 官方客户端。
- APP 不提供第三方站点账号、API Key、模型额度或注册码。
- 用户必须拥有合法的站点账号、API Key、服务器权限和内容访问权限。
- HTTP 站点可能被同一网络中的其他人窃听，涉及 Cookie、密码和 Key 时优先使用 HTTPS。
- AI、模型、站点、WebDAV 和第三方语音服务的可用性由对应服务商决定。
- 自动签到、人机验证、后台任务和候场功能受站点规则、Android 系统及手机厂商策略影响。
