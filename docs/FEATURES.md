# 功能地图：你能用它做什么？

**适用版本：0.32.194；更新日期：2026-11-26。**

公益小助手把平时分散在不同软件里的工作，合成了一条完整链路：

> **管理站点 → 自动签到 → 同步余额和 Key → 拉取并测试模型 → 本地网关统一调用 → SSH-AI 管理服务器 → LINUX.DO 浏览和朗读 → 续费和备份。**

## 站点管理

- NEWAPI、One API、SUB2API、AIHubMix 和自定义站点；

- 站点添加、编辑、删除、启停、收藏、隐藏、标签和备注；

- 搜索、筛选、状态排序、重复站点识别和批量操作；

- 网页登录、Cookie 保存、登录状态检查；

- 账户、余额、额度、用量、公告、签到和站点资料同步；

- 站点级代理、任务模式、优先级和模型配置。

## 签到和自动化

- 全自动签到、手动签到、站外签到、仅同步数据、不参与任务；

- 未登录自动授权，已登录自动进入个人中心；

- 多轮查找签到按钮；

- Cloudflare / Turnstile 人工验证后自动继续；

- 打不开自动刷新一次，仍失败自动跳过；

- Cookie / CK 失效后的后台静默自愈；

- 每个站点的成功、跳过、待登录、待验证和失败结果。

## 模型、Key 和聊天

- 多站点、多 Key 统一保存；

- Android Keystore 加密敏感凭据；

- 全站模型拉取；

- OpenAI、Codex、Claude 协议；

- 单模型、批量和全站拉取并测试；

- 模型启停、别名、分组、排序、筛选和清理；

- Cloudflare 验证后的目录继续读取；

- 流式聊天、历史会话、附件、回复朗读和服务器上下文；切换聊天模型继续当前会话，并记住上次模型与会话；
- 流式完整性：文字首段到达后开始逐步显示，较大的分片会分步补齐；支持附件输入的聊天通道及 Gemini 文字聊天使用流式回复，图片生成保留完整图片接收。上游输出额度耗尽、本机接收上限和异常断流分别提示，已经显示的文字不会因结尾报错而清空。收到上限提示后可手动发送“继续”或请模型分段回答；停止生成时保留已收到内容，不自动重发、续写或切换通道。自动记忆只处理正常完整的文字回复。

- 模型聊天 Markdown 显示：标题、粗斜体、列表、引用、代码块、链接和表格，覆盖流式回复与历史会话；

- 模型候场、通知、振动和后台保活。

## 大肥鱼

- 首页收件箱与“大肥鱼”两个入口使用约 76–80 dp 高的矩形按钮，颜色跟随主题，保留透明宠物形象；收件箱计数不受 500 封上限限制。
- 保留模型/站点/Key/协议选择、附件、人格、TTS 朗读与历史会话；切换聊天模型沿用上下文与附件。大肥鱼录音入口已移除，其他模块语音功能保持原样。
- 每条文字回复右下角提供小播放/停止按钮，复用现有回复朗读（TTS）。
- 聊天设置按钮位于自动语音开关右侧，支持常用聊天设置、个人头像、助手形象和名字；助手形象和名字同步首页。
- 全部资源联动：电影、音乐、电台、短剧、有声书、漫画与工具按后台当前启用目录查找；点击结果时重新核验资源和内容，已删除或停用的来源不沿用历史播放地址。可取得真实媒体地址的内容在聊天内显示音频或视频播放器；资源站按钮打开全部资源中对应入口。需要网页登录、站点自有播放器或暂不支持直接解析的内容，提供已核验页面或原生模块入口。搜索与解析受时间、并发和结果数量上限约束，部分来源失败会明确提示。
- 看电视：全部资源新增 IPTV 入口，支持选台、换台、搜索、收藏、节目单和全屏。在大肥鱼中可用“CCTV-1”或“中央电视一台”等名称查找频道并播放；订阅由后台管理并动态读取，订阅地址不打包在 APP 中。普通 RTMP 与常见 HTTP 媒体格式按设备解码能力播放；不支持 RTMPS、回看、录制或时移。
- LinuxDO 查询：支持最新帖子、热门帖子、关键词搜索、指定帖子正文和本人今日活动。查询依照本轮用户明确要求执行，登录及站点验证由本人完成；读取失败或部分失败会提示，旧请求结果不会串入新会话。
- 代理认证：设置 → 网络与代理，可填写 HTTP 或 SOCKS5 的用户名和密码；标准地址为 `http://user:pass@host:8080` 或 `socks5://user:pass@host:1080`。用户名和密码中的特殊字符须百分号编码，例如 `@` 写成 `%40`、`:` 写成 `%3A`、空格写成 `%20`；也兼容无认证的 `host:port`。输入默认遮挡认证信息，本机加密保存；短剧继续固定直连。
- 界面与快捷聊天：大肥鱼聊天、伙伴设置及附属面板统一为可爱伙伴风；APP 首页只改变大肥鱼按钮外观，原布局、尺寸和位置保持。空会话提供四个快捷项，“添加新记忆”仅把“请记住”填入输入框并定位到末尾，由用户补充后发送。
- 图片附件：选择图片直接打开系统照片选择器，可多选；不支持照片选择器的旧系统使用系统图片文件选择界面。拍照单独打开系统相机，拍完加入当前消息附件，取消不影响原草稿；照片预览和发送按方向信息转正。
- 自定义生图风格：保留20种预设和“遵循原始描述”，新增“自定义”；输入提示词后“保存并使用”，再次进入可编辑。切回预设会保留已保存的自定义提示词，只有选中自定义时才应用；当前请求使用发送时的风格。
- 人格设置：APP 设置 → 人格设置 → 管理人格库，以及大肥鱼 → 伙伴设置 → 人格设置，使用同一人格库。可以新建、命名、编辑、删除并切换人格；正在使用的人格须先切换后删除。当前模型专属人格优先，没有专属人格的模型继承统一人格，不重复叠加。保存人格内容与保存当前选择分别操作；发送时固定本轮人格，生成中切换从下一条消息生效。返回不保存草稿；保存冲突或失败保留编辑内容，原统一与模型人格兼容保留。
- APP 控制默认关闭；在大肥鱼设置中开启后，可以查询真实站点和分类、已接入模型、余额快照、签到记录、收件箱、日志、资源分类、备份与 WebDAV 同步状态、本地网关和聊天状态。余额与状态以本机记录和最近刷新结果为准，不将历史快照当作实时成功；代理连通测试及本人今日 LinuxDo 发帖、回复仍需明确提出。明确的单项 APP 查询由宿主直接回复真实数据，复杂查询才交给当前模型规划或分析。执行结果以真实回执为准，不向模型提供密钥、Cookie 或密码。

- APP 设置与管理：支持主题、字体、桌面图标、并发、响应超时、默认测试协议、普通代理、自动朗读与自动记忆设置；站点支持启停、收藏、隐藏、改名、删除和自动签到设置，模型支持启停或删除。可请求标记邮件已读、清空收件箱或日志，以及刷新站点/模型、签到和站点健康测试；刷新、签到、测试沿用 APP 原有任务回调。每次写操作须确认具体对象和内容；目标不明确时先补充信息，取消、失败或仅已提交任务会如实反馈，任务提交不等于完成。备份恢复、登录和文件操作仍在原页面完成。
- 聊天模型与生图模型分别配置保存，20 种内置生图风格；自然语言画图自动使用生图模型，图片返回当前会话。
- 联网搜索：大肥鱼使用独立免 Key HTTP 搜索，由手机访问公网，不经过用户 SSH 服务器，也不调用浏览器或 WebView。必应、360、搜狗、DuckDuckGo 及 RSS 备用由独立调度器处理，最多两路并发，有效结果短时缓存。普通搜索按需取得摘要与正文资料，再交由当前聊天模型回答；明确的工具任务才按需进入规划，可在步骤与时间预算内补充检索或查找本轮已读正文。普通搜索不加载 MCP 目录或 APP 私有数据，整个流程受工具步骤数、单步等待和总时限约束，随时可以停止；模型规划不可用时仍保留已取得资料。继续使用原模型调用接口，不要求模型提供原生 function-call。可以说“你自己上网去搜 Kotlin 官方文档”，也支持近期公开话题追问；缺少主题需补充，明确要求不联网时不会搜索。

- 搜索结果与限制：区分无结果、明显无关结果、验证码/访问限制、限流、超时、DNS/网络及页面解析错误；没有有效结果时不伪装搜索成功。公共搜索入口的可用性取决于网络和搜索服务，免 Key 不代表永久可用；网页正文提取不能替代登录或执行网站脚本。继续检查公网地址与 TLS，不绕过验证码，网页内容只作为资料，不能指挥 APP 执行操作。正常聊天不自动追加参考来源，执行记录仍可查看、停止和手动重试。
- 通用记忆默认开启，支持 APP 手动保存自然语言记忆要求、每轮跨模型共享，模型自动分析长期偏好/背景/约定后按对话证据校验去重；可查看、编辑、删除和关闭，可能额外调用简短模型并产生费用，不再运行旧酒馆剧情。工具过程可查看、停止及手动重试。正常完整回复结束后，后台记忆分析短暂延后；发送新消息时可取消上一轮尚未完成的记忆分析，减少与当前聊天争用模型请求额度。未完成或失败的分析不覆盖已有记忆。
- 中文技能库：保留 Anthropic、LobeHub、phuryn/pm-skills 及 OpenAI 历史目录；先显示缓存，来源到达后分批更新，详情、检测和安装按需读取正文。目录更新超时或收集取消不会清除已安装内容；保存前检查字段是否能够完整读回，本机旧超长名称等历史数据兼容保留，允许查看与卸载。每轮提供已安装且启用的兼容技能，按名称、ID 或内容匹配读取；使用公开搜索与网页读取的技能可调用内置工具。依赖 Shell、服务器、电脑环境、私网或登录态的技能仍受兼容性限制。中文介绍、可用性提示、启停、更新与卸载保留；未安装、停用或不兼容的技能不视为已执行。SSH 技能及配置保持原有只读共享方式。命中纯提示词类技能时直接用于本轮回答，不额外启动工具规划；明确需要工具的任务仍按原权限与审批规则执行。
- 通用助手设置：大肥鱼设置、智能助手设置与MCP编辑使用独立全屏页面，按功能分组，操作按钮有独立底框并跟随主题；保存后停留当前页，返回回到上一级，支持连续调整。管理审批、RPM、请求并发、文字流空闲时限、工具步骤与总时限；默认始终询问。自动审查仅自动批准内置只读工具，远程MCP仍须确认；自动批准需额外风险确认，不能替代APP设置逐项修改确认。聊天和生图仍走原站点、模型与协议，不自动重发；原协议、首段超时、历史和媒体目录入口保留。
- MCP：大肥鱼设置 → 智能助手设置 → MCP，开启“调用 SSH 本机 MCP”即自动启动SSH本机MCP服务、读取实际端口并连接，无需手填地址或另开SSH页面。页面提示“请先在 SSH AI助手里配置所需要的技能，打开 MCP 开关会自动调用。”；连接成功才保存开启状态，失败保留原设置并显示原因。仅按需初始化嵌入模块，不构建SSH页面或触发服务器自动连接；后续进入SSH复用同一引擎与MCP服务，避免重复绑定端口。关闭只断开小肥鱼，不停用SSH原服务或修改审批策略；聊天仍使用原已接入模型。普通聊天不因MCP开启而强制规划，工具请求按需进入Agent；发送立即显示准备、工具或真实模型等待阶段；消息跟随底部，上翻历史时暂停跟随。顶部“＋ 添加 MCP”可接入其他服务、编辑、启停、删除或测试连接。支持公网HTTPS Streamable HTTP和旧SSE；固定本机/私网IP的HTTP需逐配置确认明文风险，地址或认证变更需重新确认。SSH本机默认地址形如 `http://127.0.0.1:8746/sse`，采用旧SSE；单纯保存自定义地址不启动对应服务。名称可留空自动生成；保存中及失败原因在当前页面显示，失败保留输入，成功提示；目录刷新失败不阻止独立设置保存。Token本机Keystore加密并绑定源站，换机不可解密时重新授权；HTTP只限确认地址、不跟随重定向，不自动重放执行请求。SSH目录继续只读引用；沿用0.32.191的本机MCP启动与状态读取桥，不提供服务器、Shell或凭据指令；stdio、服务器、Shell及凭据工具不可用。不支持OAuth自动刷新、断线SSE恢复及MCP图片/音频渲染；本机SSE回环测试属于0.32.191的既有证据；0.32.192不修改SSH模块，沿用191的AAR及核验，不声称本轮重建SSH或重跑其测试。实际手机SSH服务和交互仍需用户验收。

## AI帮你签 V2（0.32.168）

该测试功能的首页入口已在 0.32.169 移除；原有签到机制和焚绝保持可用。功能实现记录：每站按「本地接口 → 已有会话 → 站点脚本 → AI 兜底 → 人工一次」的顺序执行，能自动的尽量不打扰人。

- **自动优先**：自动签到站点先走站点接口和本地去重，成功时零浏览器、零模型；已有会话或已学脚本的站点优先零模型回放。
- **登录策略**：优先复用加密会话快照；登录失效时自动尝试 LinuxDO 续期。密码、GitHub/Google/OIDC 等非 LinuxDO 登录会在同一个可见浏览器里请你操作一次，登录成功立即保存会话；不保存密码和 TOTP。
- **Cloudflare 盾**：非交互验证自动等待并复用 clearance；验证阶段全局串行、保持前台可见。交互式 Turnstile/reCAPTCHA 只请你点一次，不破解、不打码、不伪造指纹。
- **人工一次 → 学习**：卡住时弹出同一个浏览器，你完成登录/验证/签到后点「完成并继续」；App 只记录动作语义（不记录输入值），成功后编译成声明式脚本，下次自动回放。
- **脚本管理**：可查看步骤、删除、回滚上一版、手动触发 AI 修复；站点改版导致回放失败时自动进入 AI 修复，不覆盖仍可用的旧脚本。
- **核验与保护**：适配器状态、页面签到接口响应、页面状态三重证据；提交结果不明时保留当天保护，不重复提交。
- **报告**：每站显示阶段、模型调用次数、失败原因；需要人工的站点逐个弹出处理，可跳过或稍后继续。
- **安全边界**：模型看不到密码/验证码/Cookie/token，不能执行任意 JS；充值、支付、删除、兑换、改密、生成密钥等操作被拒绝；会话快照加密保存在本机。
