# 功能地图：你能用它做什么？

**适用版本：0.32.151；更新日期：2026-10-07。**

公益小助手把平时分散在不同软件里的工作，合成了一条完整链路：

> **管理站点 → 自动签到 → 同步余额和 Key → 拉取并测试模型 → 本地网关统一调用 → SSH-AI 管理服务器 → LINUX.DO 浏览和朗读 → 续费和备份。**

## 站点管理

- NEWAPI、One API、SUB2API、AIHubMix 和自定义站点；
- 站点添加、编辑、删除、启停、收藏、隐藏、标签和备注；
- 搜索、筛选、状态排序、重复站点识别和批量操作；
- 网页登录、Cookie 保存、登录状态检查；
- 账户、余额、额度、用量、公告、签到和站点资料同步；
- 站点级代理、任务模式、优先级和模型配置。

## 签到和自动化

- 全自动签到、手动签到、站外签到、仅同步数据、不参与任务；
- 未登录自动授权，已登录自动进入个人中心；
- 多轮查找签到按钮；
- Cloudflare / Turnstile 人工验证后自动继续；
- 打不开自动刷新一次，仍失败自动跳过；
- Cookie / CK 失效后的后台静默自愈；
- 每个站点的成功、跳过、待登录、待验证和失败结果。

## 模型、Key 和聊天

- 多站点、多 Key 统一保存；
- Android Keystore 加密敏感凭据；
- 全站模型拉取；
- OpenAI、Codex、Claude 协议；
- 单模型、批量和全站拉取并测试；
- 模型启停、别名、分组、排序、筛选和清理；
- Cloudflare 验证后的目录继续读取；
- 流式聊天、历史会话、语音输入、回复朗读和服务器上下文；
- 模型候场、通知、振动和后台保活。

## 本地 API 网关

- OpenAI 兼容 `/v1/models`；
- OpenAI 兼容 `/v1/chat/completions`、Responses `/v1/responses`、Claude `/v1/messages`；
- 复用已验证上游协议及请求/响应适配；
- SSE 流式输出；
- Bearer Key 鉴权；
- 本机回环和局域网监听；
- 多站点智能路由；
- 模型优先级和站点拖拽排序；
- 稳定性、速度、余额和价格策略；
- 请求数、Token、消耗、额度、余额和持久化日志；
- 防暴力破解和数据保留设置。

## SSH-AI 智能助手

- SSH、多会话、终端、ANSI 颜色、搜索、快捷键和命令面板；
- AI 分析日志、解释错误、生成命令和排障；
- OpenAI Chat/Responses、Claude、Gemini 协议识别、有界连接重试、重试间隔、RPM 和并发配置；
- 主题、字体、缩放、最小化保留会话、历史、朗读与自定义命令；
- RPM/并发默认不限制，重试可取消，不自动重复执行 SSH 命令；
- 文件上传、下载、重命名、删除和冲突处理；
- sudo、systemd、crontab、包管理、防火墙；
- Docker、Caddy、Nginx、Web Server；
- CPU、内存、磁盘、进程和运行指标；
- 端口转发、SOCKS5、跳板代理、本地机器和串口；
- 服务器连接导入导出、加密保险箱；
- MCP、技能和命令片段；
- 自动使用 APP 本地网关的实时地址、Key 和模型目录。

## LINUX.DO、资源和媒体

- Linux.do Connect 授权、内置论坛及保留原页面的验证流程；
- 普通网页、帖子、回复和排行榜；
- 长帖下拉增量朗读、正文过滤和去重；
- Android TTS / Edge 在线语音；
- 播放、暂停、继续、停止和悬浮控制；
- 抢注助手、公益站识别和主帖跳转；
- 资源分类、视频、直播、HLS、听书；
- DLNA 投屏、播放悬浮窗、锁屏和媒体通知。

## 激活、续费和备份

- Linux.do 身份确认；
- 注册码激活、设备绑定和自助退出；
- APP 内续费和到期页续期；
- 套餐、价格、优惠与有效期以 APP 当前页面为准；
- 二维码添加站点；
- 站点和服务器导入导出；
- 多保险箱；
- WebDAV AES-256-GCM 加密备份和恢复。

## 个性化和性能

- 深色、浅色、多套主题和桌面图标；
- 字体、字号和阅读体验；
- 站点级代理和批量并发；
- 窄屏、大字体和 Android 8.0+ 适配；
- 站点、模型列表减少重复计算；
- SSH 原生库 16KB 内存页兼容；
- 当前整包仅 ARM64（arm64-v8a），不提供 ARM32/x86 安装包。
## 短剧

- 多站源、分类、搜索、同系列推荐、追剧和观看历史；
- 视频播放、下载、预加载、投屏与切集；
- 后台下发站名、规则、停用和隐藏状态；
- 同步配置与更新目录分开操作；
- 串行分批更新，播放时为媒体处理让出资源；
- 真实站点挑战的 APP 内验证、准备提示和失败反馈；
- 本地剧库数量、文件占用与按站源多选清理，保留下载和观看数据；
- 固定直连，不继承 APP 代理、系统静态代理或旧短剧代理。

## DoH 与连接设置

- 后台可更新的预置线路与自定义 DoH；
- 独立 ECH 地址、DoH/ECH 引导 IP、IPv6 和固定连接 IP；
- APP 内 TLS/HTTP2 转接与网关模式；
- HTTP、SOCKS5、Shadowsocks 上游代理；
- DNS 缓存查看、搜索、刷新、清理及连接诊断；
- 保留证书校验；DoH 不保证免 Cloudflare 验证，也不替代站点访问权限。

## 公益榜与应用公告

- 公益站排行、站点信息及论坛主帖入口；
- 应用公告列表、正文、图片与弹窗通知；
- 按通知版本保存已读状态；无效封面降级显示，不阻断正文和列表。

操作细节见 [使用说明](USER_GUIDE.md)。站源、套餐和预置线路可能由后台更新，不以固定数量、固定价格或永久可用作承诺。
