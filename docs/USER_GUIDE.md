# 公益小助手完整使用说明

## 1. 运行要求

- Android 8.0（API 26）及以上。
- 首次激活、日常授权校验、站点同步、模型调用和更新检查均需要网络。
- 当前版本需要有效注册码。是否要求先登录 LINUX.DO 以及对应信任条件，以 APP 当时显示的激活策略为准。
- APP 不能代替站点账号，也不会提供第三方站点的额度或 API Key。
- APP 不是 LINUX.DO 官方客户端，内置浏览器与插件不代表 LINUX.DO 官方背书。

## 2. 安装与更新

1. 打开本仓库的 [Releases](https://github.com/aweijll/LINUXDO_XIAOZHUSHOU/releases/latest)。
2. 下载文件名以 `LINUXDO_XIAOZHUSHOU-` 开头的 APK。
3. 核对发布页 SHA-256；校验方法见 [下载校验说明](VERIFY_DOWNLOAD.md)。
4. 点击 APK，根据系统提示允许当前浏览器或文件管理器“安装未知应用”。
5. 更新旧版本时直接覆盖安装，不要先卸载。

系统显示“未知来源”是侧载 APK 的常规提醒。请确认下载地址属于 `github.com/aweijll/LINUXDO_XIAOZHUSHOU`，不要安装聊天群或网盘中的不明改包。

## 3. 激活与账号

首次打开后保持联网，按页面提示完成身份确认并输入有效注册码。

- **授权方式选择**：点击「使用 Linux.do 登录」后，既可以使用内置授权窗口，也可以点击**「用外部系统浏览器打开授权」**（调用系统自带 Chrome / Edge 浏览器完成官方 OAuth 授权并自动唤醒回跳 APP）。
- **人机验证提示**：当遇到 Cloudflare Turnstile 验证时，请直接在验证框中手动点击勾选；由于移除了内嵌请求头并完全放开所有跳转，各节点均可顺畅加载完成人机验证。
- **退出激活**：需要退出激活时，先在 APP 中复制并妥善保存完整注册码，再执行“退出激活”。退出会返还可用额度并停止本机使用，但不会主动删除 APP 内站点、模型和签到数据。

注册码、LINUX.DO 登录凭据和站点账号是不同概念，不要混用，也不要在 Issue 或论坛公开注册码。

## 4. 添加第一个站点

1. 进入底部“站点”页面。
2. 点击添加站点，输入完整网址，例如 `https://example.com`。
3. APP 会尝试识别 NEWAPI、One API、SUB2API 或其他类型；识别失败时可按实际情况选择自定义类型。
4. 填写站点名称、备注和标签后保存。
5. 需要网页登录时，进入站点并在内置浏览器完成登录，确认页面已登录后保存 Cookie。
6. 返回站点页执行同步，检查余额、公告、签到状态和登录状态是否正确。

同一站点尽量只保留一个规范域名。重复添加会造成任务重复、统计混乱和额外请求。

## 5. 同步数据与登录状态

“同步数据”会读取账户、余额、签到、令牌和用量等站点数据。批量同步会自动排除设置为“自定义其他类型”的站点。

- **后台自动自愈 (Auto-Repair)**：同步数据检测到某些站点 Cookie/会话失效时，系统会在后台无感知启动静默登录修复（自动识别登录入口、授权并提取最新 Cookie 保存），随后自动重新复核数据，无需人工重新进站操作。
- **误报防护**：重构了请求头和状态码识别机制，彻底解决因防爬过滤引起的“登录状态已失效”误判。

网页已登录不代表模型 API 可用：

- Cookie 用于网页和站点管理接口。
- API Key 用于 `/v1` 模型接口。

两类凭据分开保存和使用。同步失败时先确认 Cookie；模型失败时再检查 API 地址、API Key、分组和模型协议。

## 6. 自动签到强化与任务模式

站点可按实际情况选择全自动签到（焚绝-极限白嫖）、手动签到、站外签到、仅同步数据或不参与任务。

- **全自动签到正循环**：
  - **未登录站点**：页面完全加载完成后，自动点击「使用 LinuxDO 继续」-> 跳转至授权页面自动点击「允许」-> 授权回调后自动定位跳转至 `/profile` 个人中心 -> 启动多轮深度查找签到按钮（“签到 / 立即签到 / 马上签到 / 点击签到”等）-> 自动点击签到并确认结果 -> 自动保存最新 Cookie 并无缝流转下一站点。
  - **已登录站点**：精准识别右上角个人资料、用户名、额度钱包特征，自动跳转 `/profile` 执行多轮签到查找与自动点击并保存。
  - **异常自愈机制**：站点打不开时先自动刷新重试 1 次，仍打不开直接跳过避免卡死队列；遇到 Cloudflare 等安全验证框时，给予用户手动打勾时间，勾选完成后自动感知并恢复后续签到流程。
- **站外签到**：打开外部签到网址，由用户手动完成签到操作并保存当前 Cookie。
- **仅同步数据**：只更新账户和站点信息，不发起签到。
- **不参与任务**：跳过自动任务，但仍可手动进入站点。

验证码、Turnstile、Cloudflare 验证或必须本人确认的操作不会被绕过，需要在内置浏览器手动完成。

## 7. 焚绝任务报告与 AI 分析

任务结束后会生成报告，可按“任务、完成、未完成”筛选。失败信息经过脱敏后可交给 AI 分析：

- 智能：根据任务规模和错误类型自动控制分析强度。
- 简洁：给出不超过约 300 字的重点结论。
- 深度：对站点、登录、Cookie、接口、模型和任务路径进行更全面分析。

AI 报告支持 Markdown 和语音朗读。失败站点存在可信 LINUX.DO 主帖时，APP 可读取主帖正文、作者回复和近期相关反馈辅助判断。

AI 分析使用用户选定的 OpenAI 兼容模型线路。APP 会过滤 CK、API Key、Token 和 Authorization，但任务状态、站点名称及脱敏错误仍会发送到该模型服务，请选择可信线路。

## 8. 令牌管理

进入站点详情的“令牌管理”：

1. 确认 API 地址。推荐格式为 `https://域名/v1`，不要把网页个人中心路径当作 API 地址。
2. 手动刷新远程令牌。拉取到几个有效 Key，就会建立几个本地加密保存槽。
3. 从下拉菜单选择当前模型调用使用的 Key。
4. 根据站点支持情况修改令牌分组、名称、额度或状态。
5. 删除“本地保存槽”只影响本机副本；删除远程令牌会影响站点账号，请看清确认提示。

敏感凭据使用 Android Keystore 加密。不要把完整 API Key 放进站点备注、截图或公开错误报告。

## 9. 模型配置与测试

站点模型配置中可拉取 `/v1/models`、搜索模型，并选择 OpenAI、Codex Responses、Claude Messages 等协议进行真实调用测试。

- **多 APIKEY 遍历聚合**：当站点配置了多个本地有效 APIKEY 时，全站拉取会自动遍历所有 KEY，聚合获取各 KEY 名下支持的所有模型并去重展示。
- **三协议自动轮换**：拉取模型时按 OpenAI、Codex、Claude 协议依次尝试，自动匹配站点支持的调用格式。

建议流程：

1. 先确认当前 API Key 和分组正确。
2. 点击“拉取模型”。
3. 搜索目标模型，选择需要测试的协议。
4. 使用简短测试内容执行单项或批量测试。
5. 完成测试后再使用“一键删除不可用模型”；候场助手正在使用的模型会受到保护。

测试会产生真实模型请求，可能消耗少量额度。超时不一定表示 Key 无效，也可能是站点拥塞、模型满载、DNS、TLS 或网络线路问题，应结合错误原因判断。

## 10. 模型聊天与候场助手

模型聊天支持流式输出、历史会话、继续聊天和删除历史。开启朗读后，AI 新输出会自动进入语音播放；关闭后不再朗读。

输入框支持按住语音输入，松开发送，滑动取消。麦克风权限只在使用该功能时需要。

候场助手用于等待繁忙模型恢复：

- 选择站点、模型、协议、间隔和并发后启动。
- APP 通过前台服务持续探测，成功后可声音和振动提醒。
- 需要允许通知、后台运行并将电池策略设置为“不限制”。
- 不同厂商仍可能在锁屏或清理后台后终止任务，无法承诺绝对永久运行。

## 11. LINUX.DO 浏览器与插件

内置浏览器用于 LINUX.DO 授权、浏览帖子、从排行榜打开主帖和使用插件。插件中心可独立开关插件，并把常用控制添加到底部快捷导航。

语音朗读规则：

- **长帖动态追加与过滤**：向下滚动帖子时，已读回复不重复加入，新加载的回复会自动增量追加合成并顺畅跟读；彻底过滤“保存到本地”、“保存为图片”、“下载图片”等干扰操作文字。
- LINUX.DO 帖子可选择只读标题和正文，或继续朗读回复。
- 回复按“用户名回复说：内容”播报。
- 普通网页会读取可见正文。
- 图片、代码、HTML、链接和无意义符号会尽量过滤；表示金额、比例、温度、区间等数值含义的符号会保留。
- 悬浮控制支持开始、暂停、继续和停止。

选择 Edge 在线语音时，待朗读文字需要发送到语音合成服务；选择 Android 系统 TTS 时，由设备安装的语音引擎处理。

抢注助手采用页面通知与硬规则识别，不调用 AI。只有帖子时效、公益标签、API 站点识别和指定购买链接等条件同时满足时才提示。它依赖 APP 和浏览器进程存活，系统彻底杀死 APP 后无法继续监控。

## 12. 排行榜

公益站排行榜和白嫖达人排行榜采用分批加载，减少一次性请求和渲染压力。公益站条目可查看是否已添加、支持站点，并通过“主帖”进入对应 LINUX.DO 页面。

排行榜内容来自在线服务，站点可用性、备注特效和排名可能随后台数据变化。添加站点前仍应自行核对站点规则和风险。

## 13. 备份、导入与导出

普通站点导出只包含站点名称、网址、启停和优先级，不包含 Cookie、令牌或 API Key。

WebDAV 加密同步会先用独立密码进行 AES-256-GCM 加密，再上传到用户填写的 HTTPS WebDAV 地址。请牢记加密密码；密码丢失后无法恢复备份内容。

换机或卸载前建议：

1. 完成一次 WebDAV 加密上传。
2. 确认备份地址和加密密码可用。
3. 妥善保存注册码。
4. 再处理旧设备退出激活或卸载。

## 14. 权限建议

- 通知：建议允许，用于任务状态和前台服务。
- 电池优化：候场、朗读或后台任务用户建议设置为“不限制”。
- 相机：仅扫码时允许即可。
- 麦克风：仅语音输入时允许即可。
- 安装未知应用：只在 APP 内更新时临时允许，安装完成后可在系统中关闭。

APP 未申请定位、联系人或通用存储权限。

## 15. 常见问题

### 同步显示超时，但浏览器明明已登录

先进入站点确认 Cookie 已保存，再降低并发并提高单站等待时间。部分站点网页登录和管理接口会话不同，需要重新保存。自定义其他类型站点不会参与批量同步。

### 模型拉取失败

检查 API 地址是否为 `https://域名/v1`、当前 Key 是否匹配分组、站点是否允许 `/v1/models`。网页 Cookie 不能替代 API Key。

### 后台任务停止

允许通知和前台服务，在系统电池设置中选择“不限制”，并检查手机管家、自启动和锁屏清理策略。系统或厂商仍可能主动终止进程。

### 更新后数据不见了

正常覆盖安装会保留数据；先卸载再安装会删除 APP 私有数据。恢复 WebDAV 备份前确认使用了正确的加密密码。

### 如何反馈问题

提交 Issue 时写明 APP 版本、Android 版本、站点类型、操作步骤、预期结果和实际结果。所有日志和截图必须脱敏，不得包含 Cookie、API Key、Token、注册码或密码。
