# 公益小助手：从下载安装到完全上手

**适用版本：0.32.151；更新日期：2026-10-07。**

这份说明按“第一次安装 → 管理站点 → 使用模型 → 开本地网关 → 管服务器 → 备份和续费”的顺序写。照着做，不需要先研究一堆专业名词。

## 1. 先确认你适不适合用

适合这些人：

- 有多个公益 API 站点，需要统一管理；
- 每天要签到、查余额、看模型；
- 想把多个站点统一接入 NewAPI、CC Switch 或其他客户端；
- 想用手机直接管 Linux 服务器；
- 想让 AI 帮你解释日志和排查服务器；
- 经常浏览 LINUX.DO、听帖子、看资源或投屏。

运行要求：Android 8.0（API 26）及以上，仅 ARM64（arm64-v8a）。激活、站点访问、模型调用、更新和部分浏览功能需要网络。

## 2. 安装和更新

1. 打开 [GitHub Releases](https://github.com/aweijll/LINUXDO_XIAOZHUSHOU/releases/latest)。
2. 下载以 `LINUXDO_XIAOZHUSHOU-` 开头的 APK。
3. 对照发布页核对 SHA-256，方法见 [下载校验](VERIFY_DOWNLOAD.md)。
4. 根据系统提示允许浏览器或文件管理器安装未知应用。
5. 更新时直接覆盖安装，**不要卸载旧版本**。

卸载会删除 APP 私有数据。换机或重装前，先做 WebDAV 加密备份并保存注册码。

## 3. 激活和授权

首次启动保持联网，按照页面提示完成 Linux.do 身份确认和注册码激活。

默认按 APP 内置授权页完成流程。具体可用授权方式以当前页面和账号配置为准；APP 激活与论坛网页登录是不同会话。

如果出现 Cloudflare / Turnstile：

1. 不要反复刷新；
2. 在验证框中手动点击勾选；
3. 等 APP 自动继续后续流程。

注册码、Linux.do 登录身份和站点账号不是一回事，不要混用，也不要在 Issue、群聊或截图中公开。

需要退出激活时，先复制完整注册码，再执行退出。退出只停止当前设备使用，不会主动删除站点、模型和签到数据。

## 4. 添加第一个站点

1. 进入底部“站点”。
2. 点击添加站点，输入完整网址，例如 `https://example.com`。
3. APP 会尝试识别 NEWAPI、One API、SUB2API、AIHubMix 等类型。
4. 识别不准确时，按站点实际情况选择自定义类型。
5. 填写名称、备注、标签并保存。
6. 需要网页登录时，在内置浏览器完成登录，然后保存 Cookie。
7. 回到站点页，点击同步数据。

尽量使用站点的规范 HTTPS 域名，同一个站点不要重复添加多个地址，否则会造成重复任务和统计混乱。

## 5. 同步数据和登录状态

“同步数据”会读取站点账户、余额、用量、公告、签到、令牌和模型状态。

网页登录和 API 调用是两条不同链路：

- Cookie：用于网页、登录和站点管理接口；
- API Key：用于 `/v1/models`、模型测试和聊天。

Cookie 有效，不代表 API 一定可用；API Key 有效，也不代表网页一定登录。遇到问题先按这两条链路分别检查。

如果 Cookie 过期，APP 会尝试后台静默修复登录状态；修复失败时会明确提示，不会把所有错误都粗暴显示成“登录失效”。

## 6. 自动签到

站点任务模式可以选择：

- 全自动签到；
- 手动签到；
- 站外签到；
- 仅同步数据；
- 不参与任务。

全自动模式会自动处理登录、授权、进入个人中心、寻找签到按钮和保存最新 Cookie。遇到安全验证会等你手动完成，打不开的站点会自动重试一次，仍失败就跳过，不拖死整批任务。

同步或签到完成后，可以点开每个结果，查看成功、跳过、待登录、待验证和失败原因。

## 7. 配置 API Key 和模型

进入站点详情 → 令牌 / 模型配置：

1. 选择或新增 API Key；
2. 确认 API 地址，常见格式为 `https://域名/v1`；
3. 点击“拉取模型”；
4. 选择需要的模型；
5. 执行单项测试或批量测试。

模型中心支持 OpenAI、Codex、Claude 三种协议轮换测试。测试结果会告诉你是哪一个站点、哪一个协议、哪一个模型出了问题。

模型多时可以按站点、供应商、协议、可用性和名称筛选，也可以批量启停、改别名、分组和清理不可用模型。

## 8. 模型聊天和候场

模型测试通过后，进入模型聊天即可使用：

- 流式回复；
- 历史会话和继续聊天；
- 按住说话；
- 回复朗读；
- 服务器上下文；
- 工具调用和结果展示。

模型满载时可以开启“模型候场助手”，设置探测间隔和并发。成功后会通知、振动或朗读提醒。为了让它在锁屏后工作，请允许通知、前台服务，并把 APP 电池策略改为“不限制”。手机厂商仍可能清理后台。

## 9. 打开本地 API 网关

首页打开“本地网关”，进入控制台可以查看：

- 网关状态；
- 监听端口和范围；
- 模型路由；
- 价格分析；
- 请求日志；
- 用量账本；
- 设置和数据保留策略。

网关提供 OpenAI 兼容接口：

- `GET /v1/models`；
- `POST /v1/chat/completions`（OpenAI Chat Completions）；
- `POST /v1/responses`（Responses）；
- `POST /v1/messages`（Claude Messages）；
- SSE 流式输出；
- Bearer Key 鉴权。

默认优先使用本机回环地址。打开局域网监听后，同一 Wi-Fi 的其他设备也可以访问，但仍需要 Bearer Key。HTTP 局域网通信不是加密隧道，不要在不可信网络中使用。

### 接入客户端

以 OpenAI 兼容客户端为例：

- Base URL：网关显示的地址加 `/v1`；
- API Key：网关页面显示的本地客户端 Key；
- Model：网关模型列表中的模型 ID。

网关优先复用模型已验证可用的上游协议，必要时适配请求与响应。不支持的供应商扩展参数或工具能力仍可能失败。不同客户端的 Base URL 约定不同：OpenAI/Responses 客户端通常填写带 `/v1` 的地址；Claude Messages 客户端按其说明使用根地址，避免重复拼接 `/v1`。

不要把站点上游 API Key 当作本地网关 Key，也不要把本地网关 Key 发给别人。

## 10. 使用 SSH-AI

首页本地网关卡片下面点击 **SSH-AI智能助手**。

首次使用：

1. 添加服务器地址、端口、用户名和认证方式；
2. 连接服务器；
3. 在终端中确认连接；
4. 需要 AI 时，在提供方中选择“APP 本地网关”。

SSH-AI 支持终端、文件、日志、服务、端口、代理和 AI 辅助：

- 终端、ANSI 颜色、搜索、快捷键、命令面板；
- 文件上传、下载、重命名、删除和冲突处理；
- sudo、systemd、crontab、包管理、防火墙；
- Docker、Caddy、Nginx、Web Server；
- CPU、内存、磁盘、进程和运行状态；
- 端口转发、SOCKS5 和跳板代理；
- AI 分析日志、解释错误、生成命令和给出排查步骤。

“APP 本地网关”是自动托管提供方：网关启动后，SSH-AI 会自动同步当前地址、Key 和模型目录。网关停止、端口变化或 Key 重置后，提供方会自动刷新，不需要重新手工录入。

### AI 协议、重试与限流

在 SSH-AI 设置中的智能助手请求设置里调整协议、重试和限流。“APP 本地网关”由主 APP 适配已验证协议；其他提供方可按支持情况选择自动识别或明确协议，支持 OpenAI Chat、Responses、Claude 与 Gemini。

| 设置 | 可用范围与含义 |
|---|---|
| 重试间隔 | 1–300 秒 |
| 最多自动重试次数 | 0–10，0 关闭自动重试 |
| 每分钟请求数（RPM） | 0 表示不限制 |
| 同时请求数 | 0 表示不限制 |

RPM 和并发默认不限制，重试也计入 RPM。等待和连接重试可点击停止；流式中断、认证失败或结果不确定时保留记录，由你决定下一步。自动协议切换仅用于明确的接口不兼容，不会重发已经输出的内容，也不会自动重做 SSH 命令。

AI 生成的命令在执行前请自己看一遍。删除文件、修改防火墙、重启服务、改数据库等操作一定要确认目标和影响。

## 11. LINUX.DO 浏览器和朗读

内置浏览器可以完成 Linux.do 授权、浏览帖子、打开排行榜主帖和使用插件。

朗读支持：

- 标题、正文、回复和用户名；
- 下拉加载后的回复增量追加；
- 已读内容不重复；
- 自动过滤保存、下载等按钮文字；
- Android 系统 TTS 或 Edge 在线语音；
- 播放、暂停、继续、停止和悬浮控制。

### 遇到论坛验证

保存正在编辑的草稿，按页面提示进入“在 APP 内验证”。在验证窗口完成需要本人操作的验证，再按页面提示返回原页面；成功识别后可自动衔接返回。不要连续刷新或反复提交同一回复。只浏览正常不代表回帖、点赞所需的会话或权限一定有效。

验证后的凭据仍可能被服务端重新判定或撤销，不能保证固定时间内永远免验证。403 并不一定是 Cloudflare，需要结合具体错误区分站点权限、登录状态和安全挑战。

抢注助手、公益站识别、通知分类和未读角标依赖 APP 与浏览器进程存活，系统完全杀死 APP 后不会继续运行。

## 12. 资源、视频、听书和投屏

“全部资源”中可使用资源分类、视频、直播、听书和投屏能力：

- 视频和直播播放；
- HLS 等流媒体；
- DLNA 投屏；
- 播放悬浮控制；
- 听书后台播放；
- 系统媒体通知和锁屏控制。

不同资源站点的内容、可用性和版权由对应站点负责。

## 13. 续费

在设置页或到期页面进入续费：

1. 确认当前账号和授权状态；
2. 选择套餐；
3. 按 APP 页面提示完成支付；
4. 等待订单确认和授权更新。

套餐、价格、优惠和有效期以 APP 当前页面为准。不要相信私聊转账、非官方二维码或第三方代充链接。

## 14. 备份、导入和导出

建议换机、重装或退出激活前：

1. 做一次 WebDAV 加密备份；
2. 确认备份上传成功；
3. 保存独立备份密码；
4. 保存注册码；
5. 再处理旧设备。

WebDAV 使用 AES-256-GCM 加密。密码丢失后无法恢复备份。普通站点导出不包含 Cookie、API Key 或 Token。

## 15. 权限和后台设置

- 通知：用于任务、朗读、候场和网关状态；
- 前台服务：用于用户主动开启的后台任务、候场和媒体播放；
- 相机：只用于扫码；
- 麦克风：只用于语音输入；
- 安装未知应用：只用于调起系统安装器，不会静默安装；
- 电池优化：候场、朗读和后台任务建议设置为“不限制”。

资源浏览器中的网页定位可能触发定位授权，拒绝后对应网页无法取得位置；不影响普通浏览。权限说明见 [隐私与权限](PRIVACY_AND_PERMISSIONS.md)。

## 16. 常见问题

### 模型拉取失败

检查 API 地址是否带 `/v1`、Key 是否属于当前站点和分组、站点是否允许 `/v1/models`，再检查协议选择。网页 Cookie 不能替代 API Key。

### 网关客户端连不上

确认网关已开启、端口正确、客户端和手机在同一网络、Base URL 最后带 `/v1`，并使用网关当前显示的本地 Key。局域网模式下不要填写 `localhost`，应填写网关实际显示的手机局域网地址。

### SSH-AI 没有模型

先回 APP 首页开启本地网关，确认模型列表可用，再回 SSH-AI 刷新提供方。网关停止时不会自动切换到外部云服务。

### 自动签到卡住

检查通知、电池和网络；遇到 Cloudflare 时手动勾选；降低批量并发；确认站点账号和 Cookie 仍有效。

### 更新后数据不见了

覆盖安装不会主动删除数据。先确认没有卸载旧 APP；若更换设备，使用正确的 WebDAV 备份密码恢复。

### 如何反馈

提交 Issue 时写明版本、Android 版本、手机型号、站点类型、复现步骤、预期和实际结果。日志、截图和配置必须脱敏。
## 17. 短剧：源更新、验证、缓存与投屏

### 同步配置与更新内容

1. 从“全部资源”进入短剧，打开站源管理/源列表。
2. 同步后台源配置：用于更新站名、规则、启停和隐藏状态。
3. 选择需要的站源更新内容：用于读取该站剧目目录，和同步配置是两个操作。
4. 使用搜索、分类或同系列推荐找剧，进入详情播放，也可追剧、查看历史或下载。

后台修改必须发布后才能下发。隐藏的源不会出现在正常源列表，停用的源不能继续发起新的访问；已下载内容和本地历史不会因此自动删除。源列表随后台维护变化，不以固定站源数量作保证。

0.32.150 起，更新进入单工作队列。自动批次读取首页和有限历史页，保留继续加载能力；播放或媒体处理时暂停启动后续更新。显示“排队”不等于失败，不要反复发起全量更新。

### “需要浏览器验证”或 403

点击“在 APP 内验证”，先等待准备提示，再在内置窗口完成验证。成功后继续原更新；失败或取消时查看提示，不要重复快速提交。挑战记录已失效时 APP 会重新检查当前站点，已经恢复访问则直接继续。

普通 403、会员限制、站点故障及限流不一定能靠验证解决。请求过多时先等待；需要账号或会员的内容仍受站点自身权限限制。

短剧固定直连，不使用 APP 代理或系统静态代理。系统 VPN、广告过滤与运营商网络仍可能影响请求；开启 APP DoH 不代表短剧会改走 DoH 路线。

### 清理本地剧库

1. 短剧设置 → **清除缓存**。
2. 查看“本地剧库缓存”的剧目数量和占用，必要时点“刷新占用”。
3. 展开站源列表，勾选多个站源或“全选站源”。
4. 点击“清理选中剧库缓存”，确认后等待完成。

总文件占用使用实际共享文件大小；单源分摊和受限可见范围的占用会标为估算。剧目按 ID 去重，分类计数不一定能直接相加。已下架站源的遗留缓存也可清理。

清理会协调正在进行的读取、取消选中源更新，避免旧响应把数据立即写回；不会删除下载视频、追剧、观看记录、用户设置或站源配置。清理后重新更新该源会再次占用空间。

### 播放器投屏

手机和接收设备连接同一局域网，在短剧播放器打开投屏入口并选择设备。支持设备发现、播放控制、切集与返回本机；具体格式和字幕支持取决于接收端。路由器客户端隔离、多播限制或 VPN 可能影响发现，部分格式需要使用页面提供的镜像方案。

## 18. 代理与 DoH

设置 → 代理设置中选择需要的模式，保存后按需测试。站点还有独立代理开关，应同时确认当前站点是否启用代理。

DoH 可选择后台下发的预置线路，也可填写自定义 HTTPS 地址。随包预置包含 `https://edge.1molchuan.top/linuxdo` 和 `https://edge.1molchuan.top/plus`；后台可更新预置列表，以当前同步结果为准。

| 高级选项 | 用途 |
|---|---|
| ECH DoH 地址 | 独立解析 ECH 信息，留空使用当前 DoH |
| DoH/ECH 引导 IP | 解析服务域名本身无法解析时使用；仍校验对应域名证书 |
| IPv6 优先、固定连接 IP | 按实际网络选择；固定 IP 不改变域名证书校验 |
| TLS 转接与 ECH、HTTP/2 转接、网关模式 | APP 内连接兼容选项，按线路支持情况设置 |
| 上游代理 | 可配置 HTTP、SOCKS5 或 Shadowsocks 的地址、端口及认证 |
| DNS 缓存 | 查看、搜索、刷新已缓存域名和清理 |

初次使用先测试选定线路，只有确有需要时再调整高级设置。测试成功只表示当时测试链路可用，不代表所有站点、回帖和点赞都获得权限。DoH 本身不保证代理可达，也不保证永久免验证；移动网络失败但某条上游代理成功，应分别检查解析、TLS、线路可达性和错误代码。

TLS 转接只在 APP 内生效，不要求安装系统证书；验证服务保留端到端连接。不要为排障关闭证书校验。

## 19. 应用公告与更新问题

在 APP 设置打开“应用公告”查看列表和正文。弹窗由后台开关及通知版本控制，已确认的同一条通知不会每次启动都重复弹出。0.32.150 修复无封面公告导致整批读取失败；升级后重新打开 APP，保持网络可用再查看。

应用公告和 Android 通知栏是两种入口，未收到通知栏提示不代表公告列表为空。仍异常时，请提供版本、操作步骤和脱敏错误。

APP 内安装更新需要系统安装器及当前应用的“安装未知应用”许可。遇到安装器不可用时，可从官方 Releases 下载同一版本交给系统文件管理器安装，先确认架构、签名及设备安装限制，不要卸载旧版本来碰运气。
