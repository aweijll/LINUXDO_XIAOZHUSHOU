# 公益小助手：从下载安装到完全上手

**适用版本：0.32.197；更新日期：2026-11-26。**

本次更新：

1. 修复部分 IPTV 断流后无法恢复的问题，新增断流自动重连。
2. 优化大肥鱼与全部资源的对接，改进音乐、影视搜索及聊天内播放。
3. 优化资源搜索理解、解析反馈与取消操作，修复部分已知问题。

这份说明按“第一次安装 → 管理站点 → 使用模型 → 开本地网关 → 管服务器 → 备份和续费”的顺序写。照着做，不需要先研究一堆专业名词。

## 1. 先确认你适不适合用

适合这些人：

- 有多个公益 API 站点，需要统一管理；

- 每天要签到、查余额、看模型；

- 想把多个站点统一接入 NewAPI、CC Switch 或其他客户端；

- 想用手机直接管 Linux 服务器；

- 想让 AI 帮你解释日志和排查服务器；

- 经常浏览 LINUX.DO、听帖子、看资源或投屏。

运行要求：Android 8.0（API 26）及以上，仅 ARM64（arm64-v8a）。激活、站点访问、模型调用、更新和部分浏览功能需要网络。

## 2. 安装和更新

1. 打开 [GitHub Releases](https://github.com/aweijll/LINUXDO_XIAOZHUSHOU/releases/latest)。

2. 下载以 `LINUXDO_XIAOZHUSHOU-` 开头的 APK。

3. 对照发布页核对 SHA-256，方法见 [下载校验](VERIFY_DOWNLOAD.md)。

4. 根据系统提示允许浏览器或文件管理器安装未知应用。

5. 更新时直接覆盖安装，**不要卸载旧版本**。

卸载会删除 APP 私有数据。换机或重装前，先做 WebDAV 加密备份并保存注册码。

## 3. 激活和授权

首次启动保持联网，按照页面提示完成 Linux.do 身份确认和注册码激活。

本版隐藏了激活页的内置 LinuxDo 登录按钮，保留“浏览器授权”入口。点击“浏览器授权”后，在系统浏览器完成 LinuxDo 登录、本人验证和同意授权；返回 APP 后点击“已授权，继续”确认状态，再按提示绑定注册码。

外置浏览器授权方式保持原样，使用浏览器自身的网络设置与登录会话；是否需要代理取决于浏览器实际能否访问 LinuxDo。若需更换账号，请先在外置浏览器确认当前登录账号。

后台身份确认和注册码绑定仍由服务端处理。家庭备用需能够访问 LinuxDo；两个出口都不可用时，需要恢复可用连接再重新授权。APP 激活与论坛网页登录是不同会话。

若初始连接失败，页面会结束等待并提供重试提示。“设置 → 应用与账号 → 接口线路”中的延迟按各条线路完成顺序显示；它是 HTTP 服务探测耗时，包含连接与服务响应，不是 ICMP ping。

遇到 Cloudflare / Turnstile 等本人验证时，请在浏览器按网页提示完成，避免反复刷新；页面打开不等于已完成身份确认。

注册码、Linux.do 登录身份和站点账号不是一回事，不要混用，也不要在 Issue、群聊或截图中公开。

需要退出激活时，先复制完整注册码，再执行退出。退出只停止当前设备使用，不会主动删除站点、模型和签到数据。

## 4. 添加第一个站点

1. 进入底部“站点”。

2. 点击添加站点，输入完整网址，例如 `https://example.com`。

3. APP 会尝试识别 NEWAPI、One API、SUB2API、AIHubMix 等类型。

4. 识别不准确时，按站点实际情况选择自定义类型。

5. 填写名称、备注、标签并保存。

6. 需要网页登录时，在内置浏览器完成登录，然后保存 Cookie。

7. 回到站点页，点击同步数据。

尽量使用站点的规范 HTTPS 域名，同一个站点不要重复添加多个地址，否则会造成重复任务和统计混乱。

## 5. 同步数据和登录状态

“同步数据”会读取站点账户、余额、用量、公告、签到、令牌和模型状态。

网页登录和 API 调用是两条不同链路：

- Cookie：用于网页、登录和站点管理接口；

- API Key：用于 `/v1/models`、模型测试和聊天。

Cookie 有效，不代表 API 一定可用；API Key 有效，也不代表网页一定登录。遇到问题先按这两条链路分别检查。

如果 Cookie 过期，APP 会尝试后台静默修复登录状态；修复失败时会明确提示，不会把所有错误都粗暴显示成“登录失效”。

## 6. 自动签到

站点任务模式可以选择：

- 全自动签到；

- 手动签到；

- 站外签到；

- 仅同步数据；

- 不参与任务。

全自动模式会自动处理登录、授权、进入个人中心、寻找签到按钮和保存最新 Cookie。遇到安全验证会等你手动完成，打不开的站点会自动重试一次，仍失败就跳过，不拖死整批任务。

同步或签到完成后，可以点开每个结果，查看成功、跳过、待登录、待验证和失败原因。

## 7. 配置 API Key 和模型

进入站点详情 → 令牌 / 模型配置：

1. 选择或新增 API Key；

2. 确认 API 地址，常见格式为 `https://域名/v1`；

3. 点击“拉取模型”；

4. 选择需要的模型；

5. 执行单项测试或批量测试。

模型中心支持 OpenAI、Codex、Claude 三种协议轮换测试。测试结果会告诉你是哪一个站点、哪一个协议、哪一个模型出了问题。

模型多时可以按站点、供应商、协议、可用性和名称筛选，也可以批量启停、改别名、分组和清理不可用模型。

## 8. 模型聊天和候场

模型测试通过后，进入模型聊天即可使用：

- 流式回复：文字首段到达后开始逐步显示，较大的分片会分步补齐；支持附件输入的聊天通道及 Gemini 文字聊天使用流式回复，图片生成保留完整图片接收。上游输出额度耗尽、本机接收上限和异常断流分别提示，已经显示的文字不会因结尾报错而清空。收到上限提示后可手动发送“继续”或请模型分段回答；停止生成时保留已收到内容，不自动重发、续写或切换通道。自动记忆只处理正常完整的文字回复。

- Markdown 格式：标题、粗体、斜体、列表、引用、代码块、链接和表格；用户消息、实时回复和历史聊天均支持；代码块和宽表格可横向滑动；

- 历史会话和继续聊天；

- 附件输入（大肥鱼已移除录音入口）；

- 回复朗读；

- 服务器上下文；

- 工具调用和结果展示。

模型满载时可以开启“模型候场助手”，设置探测间隔和并发。成功后会通知、振动或朗读提醒。为了让它在锁屏后工作，请允许通知、前台服务，并把 APP 电池策略改为“不限制”。手机厂商仍可能清理后台。

### 大肥鱼：从首页直接聊天

首页点击收件箱右侧的“大肥鱼”。两个入口使用约 76–80 dp 高的矩形按钮，界面跟随 APP 主题。仍使用已接入的站点与模型，保留附件、人格编辑、回复朗读（TTS）和历史会话；大肥鱼录音入口已移除，其他模块语音功能保持原样。收件箱总数不受 500 封限制。

- 朗读：每条文字回复右下角提供小播放/停止按钮，复用现有回复朗读（TTS）；点击播放可朗读该条回复，点击停止可停止朗读。
- 聊天设置：聊天设置按钮位于自动语音开关右侧，可调整常用聊天设置、个人头像、助手形象和名字；助手形象和名字同步首页。
- 全部资源联动：电影、音乐、电台、短剧、有声书、漫画和 IPTV 按后台当前启用目录查找；将请求分成内容类型、作品或作者、资源站范围，去掉“帮我找”“播放”等指令文字后检索。紧接资源结果可以追问“那《三体》呢”“换成晴天”或“重新搜一下”；普通聊天后的新问题不会沿用旧资源主题。搜索与点击播放前后核对当前目录，删除、停用或更换入口的来源不能继续使用旧结果。音乐和影视只把真实内容返回为作品按钮；找不到、需登录、解析失败或超时分别说明，不使用无关作品或资源站入口充当已找到的内容。听书排队计入总等待预算，取消后不继续提交旧结果。
- 音乐播放：已适配音乐站的五个平台来源，按歌曲名与歌手匹配，解析失败时尝试匹配的备用音源；正式播放前检查返回的是音频或可识别媒体，拒绝将网页或错误响应当作歌曲。私人音乐沿用全部资源中该站的登录状态；提示需登录时先打开资源站完成登录，再重新搜索。解析、等待和取消都有边界，失败时可换来源或使用资源站继续播放；音源是否可用仍取决于站点。
- 影院播放：已适配影院按真实片名检索，点击后重新读取影片详情和播放线路，支持已核验的普通片源、Emby、OpenList 及部分脚本/TVBox 线路。影院沿用全部资源中该站的登录状态；默认从第 1 集或正片开始，需要选集、额外解析、特殊请求头或站内鉴权的线路可前往资源站。演员、导演或复杂条件不保证能在所有片源中检索，可补充具体片名。
- 看电视：全部资源 → IPTV 支持选台、换台、搜索、收藏、节目单和全屏。在大肥鱼中可用“CCTV-1”或“中央电视一台”等名称查找频道并播放。订阅由后台管理并动态读取，订阅地址不打包在 APP 中；账号配置独立通过受信 HTTPS 主备线路取得，不受所选 HTTP 资源线路影响。订阅、节目单与播放地址支持 HTTP/HTTPS；这些请求及频道封面固定直连，不继承 APP、系统静态或环境代理，系统 VPN 路由仍然有效。域名解析异常时按安全规则尝试备用解析，继续校验公网目标与 TLS；加载失败区分配置、订阅或网络原因。普通 RTMP 与常见 HTTP 媒体格式按设备解码能力播放；不支持 RTMPS、回看、录制或时移。断流时保留错误信息，对可恢复故障按 1、3、8 秒间隔最多自动重连 3 次；等待和重试有状态提示，达到上限后可手动重试。换台、取消或离开播放时不会继续旧频道重连。
- LinuxDO：通过 APP 原论坛入口浏览、搜索和使用已登录功能；大肥鱼可检索公开网页，但不读取论坛登录态或本人活动。
- 代理认证：设置 → 网络与代理，可填写 HTTP 或 SOCKS5 的用户名和密码；标准地址为 `http://user:pass@host:8080` 或 `socks5://user:pass@host:1080`。用户名和密码中的特殊字符须百分号编码，例如 `@` 写成 `%40`、`:` 写成 `%3A`、空格写成 `%20`；也兼容无认证的 `host:port`。输入默认遮挡认证信息，本机加密保存；短剧继续固定直连。
- 界面与快捷聊天：大肥鱼聊天、伙伴设置及附属面板统一为可爱伙伴风；APP 首页只改变大肥鱼按钮外观，原布局、尺寸和位置保持。空会话提供四个快捷项，“添加新记忆”仅把“请记住”填入输入框并定位到末尾，由用户补充后发送。

- 自定义生图风格：保留20种预设和“遵循原始描述”，新增“自定义”；输入提示词后“保存并使用”，再次进入可编辑。切回预设会保留已保存的自定义提示词，只有选中自定义时才应用；当前请求使用发送时的风格。

- APP 控制已移除：大肥鱼不再读取或修改本机站点、账号、模型、代理、收件箱、日志和设置，也不再通过聊天调用签到、导航或论坛登录态读取。原 APP 各管理页面仍可手动使用。已有聊天与记忆保留，旧版控制开关不会恢复这项能力。

- 模型与会话：切换聊天模型时沿用当前会话、上下文和附件；再次进入时恢复上次使用的模型与会话。
- 生图：分别选择并保存聊天模型和生图模型，切换其中一个不会覆盖另一个。选择 20 种内置风格之一，或直接用自然语言要求画图；请求自动交给已配置的生图模型，图片返回当前会话。

- 联网：大肥鱼使用独立免 Key HTTP 搜索，不依赖 SSH 服务器，不自动打开浏览器或 WebView。结合当前问题与紧邻对话判断回答和工具需求；需要搜索时恢复主题，保留指定站点和关键词限制，并按主题相关性筛选结果。请求 GitHub 热门项目时读取 GitHub 官方当日榜单，避免使用旧转载文章代替当前项目。先读取相关来源，再将真实摘要与正文交给当前聊天模型组织回答；证据不足时说明缺失，不将无关结果算作成功。普通搜索独立于 MCP 和技能工具规划，保留来源备用、短时缓存、有界并发与取消。使用原模型接口，无需模型原生 function-call；明确要求不联网时不会搜索。

网页读取兼容公开 HTML、JSON、RSS 和 Atom，并提取页面公开的结构化正文。需要登录、人机验证或仅靠脚本生成且没有公开正文的页面仍可能无法读取，会如实提示原因。

## 9. 打开本地 API 网关

首页打开“本地网关”，进入控制台可以查看：

- 网关状态；

- 监听端口和范围；

- 模型路由；

- 价格分析；

- 请求日志；

- 用量账本；

- 设置和数据保留策略。

网关提供 OpenAI 兼容接口：

- `GET /v1/models`；

- `POST /v1/chat/completions`（OpenAI Chat Completions）；

- `POST /v1/responses`（Responses）；

- `POST /v1/messages`（Claude Messages）；

- SSE 流式输出；

- Bearer Key 鉴权。

默认优先使用本机回环地址。打开局域网监听后，同一 Wi-Fi 的其他设备也可以访问，但仍需要 Bearer Key。HTTP 局域网通信不是加密隧道，不要在不可信网络中使用。

### 接入客户端

以 OpenAI 兼容客户端为例：

- Base URL：网关显示的地址加 `/v1`；

- API Key：网关页面显示的本地客户端 Key；

- Model：网关模型列表中的模型 ID。

网关设置中的“上游模型协议”可选择自动、OpenAI Chat、Responses、Claude 或 Gemini。自动按已验证线路选择；手动选择只使用对应已验证协议，缺少可用线路时明确报错。必要时适配请求与响应。不支持的供应商扩展参数或工具能力仍可能失败。不同客户端的 Base URL 约定不同：OpenAI/Responses 客户端通常填写带 `/v1` 的地址；Claude Messages 客户端按其说明使用根地址，避免重复拼接 `/v1`。

不要把站点上游 API Key 当作本地网关 Key，也不要把本地网关 Key 发给别人。

## 10. 使用 SSH-AI

首页本地网关卡片下面点击 **SSH-AI智能助手**。

首次使用：

1. 添加服务器地址、端口、用户名和认证方式；

2. 连接服务器；

3. 在终端中确认连接；

4. 需要 AI 时，在提供方中选择“APP 本地网关”。

SSH-AI 支持终端、文件、日志、服务、端口、代理和 AI 辅助：

- 终端、ANSI 颜色、搜索、快捷键、命令面板；

- 文件上传、下载、重命名、删除和冲突处理；

- sudo、systemd、crontab、包管理、防火墙；

- Docker、Caddy、Nginx、Web Server；

- CPU、内存、磁盘、进程和运行状态；

- 端口转发、SOCKS5 和跳板代理；

- AI 分析日志、解释错误、生成命令和给出排查步骤。

“APP 本地网关”是自动托管提供方：网关启动后，SSH-AI 会自动同步当前地址、Key 和模型目录。网关停止、端口变化或 Key 重置后，提供方会自动刷新，不需要重新手工录入。

### SSH 智能助手联网

在原智能助手内请求联网搜索或阅读公开网页，结果附带来源引用。搜索优先中国 Bing RSS，失败使用备用来源，网页阅读兼容 JSON 内容；系统 DNS 返回 FakeIP 时通过受信 DoH 重新解析并检查全部地址，保持公网地址与 TLS 校验。原模型/提供方选择、入口、附件、历史和命令权限保留；网页内容只作参考，不取得服务器命令权限。

### AI 协议、重试与限流

在 SSH-AI 设置中的“模型协议与连接”调整协议、重试和限流。

“本地网关入口协议”默认跟随网关，也可选 Chat、Responses、Claude；它控制 SSH 到网关的请求。“上游模型协议”控制网关到站点，两处负责不同连接，推荐保持跟随以减少转换。修改网关设置后下次请求生效。自定义提供方协议单独配置，支持 OpenAI Chat、Responses、Claude 与 Gemini。

| 设置 | 可用范围与含义 |

|---|---|

| 固定重试间隔 | 1–300 秒；服务端要求更长等待时会明确提示 |

| 每个任务最多重试次数 | 0–10，工具后续请求共享预算，0 关闭 |

| 每分钟请求数（RPM） | 0 表示不限制 |

| 同时请求数 | 0 表示不限制 |

| 等待响应头 | 15–1800 秒 |

| 流无活动超时 | 15–1800 秒，收到内容或心跳会延长等待 |

RPM 和并发默认不限制，重试也计入 RPM。等待和连接重试可点击停止；流式中断、认证失败或结果不确定时保留记录，可点击“继续未完成回复”接着处理；已完成的工具结果会保留，未获批准或结果未知的操作需要先核实。自动协议切换仅用于明确的接口不兼容，不会重发已经输出的内容，也不会自动重做 SSH 命令。

AI 生成的命令在执行前请自己看一遍。删除文件、修改防火墙、重启服务、改数据库等操作一定要确认目标和影响。

### 选择朗读引擎

打开 APP「设置 → 中文朗读」，可选择系统、Edge、百度翻译、Google 翻译或自动备用。以上在线选项无需填写 API Key。百度提供普通话，Google 提供普通话和台湾华语；需要更多命名音色可选择 Edge。

系统模式可选择手机上已安装的 TTS 引擎，音色列表标明离线或联网；缺少中文语音包时，点击“打开系统语音设置 / 下载语音包”。APP 不会自动安装引擎或下载语音包。

## 14. 备份、导入和导出

进入 APP「设置 → 数据与备份」。论坛设置里的备份入口也会打开这里。

| 操作 | 用法 |
| --- | --- |
| 备份全部数据 | 生成 ZIP，包含站点、API Key/Cookie、设置、论坛聊天、SSH 安全存储和纳入范围的本地文件。此本地文件未加密，请妥善保管。 |
| 选择备份还原 | 可选择新 ZIP、旧版全量 JSON、旧论坛设置 JSON 或旧站点导出。旧论坛 JSON 仅导入论坛设置，不替换整个 APP。 |
| WebDAV 加密同步 | 与本地全量备份范围一致，使用 AES-256-GCM；上传与下载恢复分开操作。 |

全量恢复在确认覆盖范围后，先检查文件完整性并准备数据库迁移，全部预检通过才在重启时替换数据。旧数据库通过现有迁移升级，无需与当前建表文本完全相同；高于当前 APP 的数据库需要先升级 APP。预检失败不会覆盖原数据，替换失败会尝试回滚。完成后 APP 会重启；若系统未自动打开，请手动启动。

论坛旧 JSON 导入先校验各项设置，兼容旧类型并忽略未知设置类型。成功后重新打开论坛使设置生效。全量恢复也会处理论坛及 SSH 共用的安全存储，无需先进入 SSH。

SSH 备份保留字号、界面缩放等设置的数字类型。已恢复过旧备份的设备会在进入 SSH 时修正这些数字设置，无需清除数据或重新导入；启动失败时显示具体阶段，点「重新加载」可重新读取。

### WebDAV 使用步骤

1. 填写 WebDAV 目录或文件地址、用户名和登录密码。目录地址默认使用 `aihub_backup.json`；也支持指定 `.json`、`.sync`、`.zip`、`.backup` 文件。
2. 设置至少 8 位的独立备份加密密码。保存配置和测试连接不会开启自动上传。连接测试会区分文件尚未创建、读取权限和服务器报告的写入权限；未报告的写入权限需实际上传确认。
3. 点「上传本机备份」并确认最近结果成功。支持 MOVE 的服务器先上传临时文件再替换目标；服务器明确不支持时使用普通 PUT。
4. 需要恢复时，填写备份原来的加密密码，点「下载并恢复」。下载前暂停自动上传，恢复后保持暂停，确认数据正确后再手动开启。
5. 按需开启「自动上传」：开启后立即尝试上传，每 12 小时调度一次，打开 APP 时补传；实际时间受系统后台和网络条件影响。它不会自动下载或合并两台设备的数据。

修改加密密码不会重新加密已有云端文件；密码丢失无法解密。网络中断且写入结果未知时，不自动重复覆盖云端文件；检查最近结果与云端备份后再操作。多台设备上传同一文件会互相替换，请分别设置文件地址。

备份不包含可重建网络缓存、系统权限、设备生物识别和短剧离线下载。目标设备的激活授权不会从旧备份克隆；SSH 保险箱仍使用备份时的保险箱密码。换机前保存注册码、加密密码并确认备份成功，更新请覆盖安装。

## 16. 常见问题

### 模型拉取失败

检查 API 地址是否带 `/v1`、Key 是否属于当前站点和分组、站点是否允许 `/v1/models`，再检查协议选择。网页 Cookie 不能替代 API Key。

### 网关客户端连不上

确认网关已开启、端口正确、客户端和手机在同一网络、Base URL 最后带 `/v1`，并使用网关当前显示的本地 Key。局域网模式下不要填写 `localhost`，应填写网关实际显示的手机局域网地址。

### SSH-AI 没有模型

先回 APP 首页开启本地网关，确认模型列表可用，再回 SSH-AI 刷新提供方。网关停止时不会自动切换到外部云服务。

### 自动签到卡住

检查通知、电池和网络；遇到 Cloudflare 时手动勾选；降低批量并发；确认站点账号和 Cookie 仍有效。

### 更新后数据不见了

覆盖安装不会主动删除数据。先确认没有卸载旧 APP；若更换设备，使用正确的 WebDAV 备份密码恢复。

### 如何反馈

提交 Issue 时写明版本、Android 版本、手机型号、站点类型、复现步骤、预期和实际结果。日志、截图和配置必须脱敏。

## 17. 短剧：源更新、验证、缓存与投屏

### 同步配置与更新内容

1. 从“全部资源”进入短剧，打开站源管理/源列表。

2. 同步后台源配置：用于更新站名、规则、启停和隐藏状态。

3. 选择需要的站源更新内容：用于读取该站剧目目录，和同步配置是两个操作。

4. 使用搜索、分类或同系列推荐找剧，进入详情播放，也可追剧、查看历史或下载。

后台修改必须发布后才能下发。隐藏的源不会出现在正常源列表，停用的源不能继续发起新的访问；已下载内容和本地历史不会因此自动删除。源列表随后台维护变化，不以固定站源数量作保证。

0.32.150 起，更新进入单工作队列。自动批次读取首页和有限历史页，保留继续加载能力；播放或媒体处理时暂停启动后续更新。显示“排队”不等于失败，不要反复发起全量更新。

### “需要浏览器验证”或 403

点击“在 APP 内验证”，先等待准备提示，再在内置窗口完成验证。成功后继续原更新；失败或取消时查看提示，不要重复快速提交。挑战记录已失效时 APP 会重新检查当前站点，已经恢复访问则直接继续。

普通 403、会员限制、站点故障及限流不一定能靠验证解决。请求过多时先等待；需要账号或会员的内容仍受站点自身权限限制。

短剧固定直连，不使用 APP 代理或系统静态代理。系统 VPN、广告过滤与运营商网络仍可能影响请求；开启 APP DoH 不代表短剧会改走 DoH 路线。

### 清理本地剧库

1. 短剧设置 → **清除缓存**。

2. 查看“本地剧库缓存”的剧目数量和占用，必要时点“刷新占用”。

3. 展开站源列表，勾选多个站源或“全选站源”。

4. 点击“清理选中剧库缓存”，确认后等待完成。

总文件占用使用实际共享文件大小；单源分摊和受限可见范围的占用会标为估算。剧目按 ID 去重，分类计数不一定能直接相加。已下架站源的遗留缓存也可清理。

清理会协调正在进行的读取、取消选中源更新，避免旧响应把数据立即写回；不会删除下载视频、追剧、观看记录、用户设置或站源配置。清理后重新更新该源会再次占用空间。

### 播放器投屏

手机和接收设备连接同一局域网，在短剧播放器打开投屏入口并选择设备。支持设备发现、播放控制、切集与返回本机；具体格式和字幕支持取决于接收端。路由器客户端隔离、多播限制或 VPN 可能影响发现，部分格式需要使用页面提供的镜像方案。

## 18. 代理与 DoH

从 0.32.173—0.32.176 更新后，如果此前仅选择“跟随后台默认”而没有保存具体 DoH 地址，请在网络与代理设置中重新选择一次线路；已有手选线路保留。正在进行的登录可能需要重新发起。

设置 → 网络与代理中选择需要的模式，保存后按需测试。站点还有独立代理开关，应同时确认当前站点是否启用代理。

DoH 可选择后台下发的预置线路，也可填写自定义 HTTPS 地址。随包预置包含 `https://edge.1molchuan.top/linuxdo` 和 `https://edge.1molchuan.top/plus`；后台可更新预置列表，以当前同步结果为准。

| 高级选项 | 用途 |

|---|---|

| ECH DoH 地址 | 独立解析 ECH 信息，留空使用当前 DoH |

| DoH/ECH 引导 IP | 解析服务域名本身无法解析时使用；仍校验对应域名证书 |

| IPv6 优先、固定连接 IP | 按实际网络选择；固定 IP 不改变域名证书校验 |

| TLS 转接与 ECH、HTTP/2 转接、网关模式 | APP 内连接兼容选项，按线路支持情况设置 |

| 上游代理 | 可配置 HTTP、SOCKS5 或 Shadowsocks 的地址、端口及认证 |

| DNS 缓存 | 查看、搜索、刷新已缓存域名和清理 |

初次使用先测试选定线路，只有确有需要时再调整高级设置。测试成功只表示当时测试链路可用，不代表所有站点、回帖和点赞都获得权限。DoH 本身不保证代理可达，也不保证永久免验证；移动网络失败但某条上游代理成功，应分别检查解析、TLS、线路可达性和错误代码。

TLS 转接只在 APP 内生效，不要求安装系统证书；验证服务保留端到端连接。不要为排障关闭证书校验。
