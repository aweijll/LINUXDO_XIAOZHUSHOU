# 隐私、安全与权限说明

## 数据保存在何处

站点 Cookie、API Key、激活令牌和 WebDAV 配置等敏感数据保存在 APP 私有目录，并使用 Android Keystore 提供的密钥进行加密。APP 关闭 Android 系统自动备份，避免私有数据直接进入系统云备份或设备迁移。

普通站点导出不包含 Cookie、令牌或 API Key。WebDAV 同步包会在上传前使用用户设置的独立密码加密。

卸载 APP 会删除其私有数据。需要换机或重装时，请先完成加密备份并保存注册码。

## 哪些操作会访问网络

- 激活、在线授权状态与更新检查会访问应用服务。
- LINUX.DO 身份确认、浏览和插件功能会访问 LINUX.DO 及插件明确需要的目标地址。
- 签到、同步、登录检查和公告会访问用户添加的站点。
- 模型拉取、测试、聊天和 AI 报告会访问用户选择的模型 API。
- WebDAV 备份会访问用户填写的 WebDAV 地址。
- 选择 Edge 在线语音时，待朗读文字会发送到语音合成服务；系统 TTS 则由设备语音引擎处理。

第三方站点、模型服务和 WebDAV 的日志及隐私政策不由本 APP 控制。只应配置自己信任的服务。

## AI 报告的数据边界

AI 报告会对任务信息做脱敏，避免发送 CK、Cookie、API Key、Token、Authorization 和 URL 查询秘密。任务状态、站点名称、脱敏错误及必要的主帖证据仍会发送给用户选择的模型端点。

不要在站点名称、备注或错误描述中主动填写个人隐私或秘密。高度敏感场景请不要使用 AI 分析。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| 网络、网络状态 | 激活、更新、站点同步、签到、模型调用和网页浏览 |
| 相机 | 用户主动扫描二维码；设备无相机不影响其他功能 |
| 麦克风 | 模型聊天按住说话的语音输入 |
| 通知 | 显示后台任务、朗读和候场状态 |
| 前台服务、唤醒锁、电池优化豁免 | 用户主动开启的模型候场、浏览器保持、朗读和后台任务 |
| 媒体播放前台服务 | 听书和语音播放控制 |
| 振动 | 模型可用和任务提示 |
| 安装未知应用 | 下载更新后调起 Android 系统安装确认，不会静默安装 |

APP 未申请定位、联系人或通用存储权限。拒绝相机或麦克风权限只会关闭对应功能。

## HTTP 风险

为兼容用户自定义的旧站点，APP 允许访问明文 HTTP。HTTP 无法防止同一网络中的中间人读取或篡改通信；涉及 Cookie、密码或 API Key 时应优先选择 HTTPS。

## 后台运行限制

模型候场、朗读和监控依赖 Android 前台服务及厂商后台策略。即使已授予通知和电池优化豁免，系统仍可能在内存紧张、手动强制停止或厂商清理时终止进程，APP 不承诺绝对永久运行。

## 反馈安全

在 GitHub Issue 或论坛反馈时，不要提交以下内容：

- Cookie、CK、API Key、Token、Authorization；
- 注册码、密码、WebDAV 凭据；
- 未脱敏的请求头、数据库、备份文件；
- 能直接登录账号的二维码或截图。

只需提供版本、系统、站点类型、复现步骤和脱敏错误提示。
